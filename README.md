# Skincare Chatbot

A skincare consultant chatbot built with Streamlit, SQLite, and LangChain. It recommends skincare products for different skin types (berminyak, kering, kombinasi, berjerawat, sensitif) in Bahasa Indonesia.

## Setup

1. Install Miniconda: [conda.io](https://docs.conda.io/en/latest/miniconda.html).
2. Create a Conda environment:
   ```bash
   conda create -n skincare_chatbot python=3.9
   conda activate skincare_chatbot
